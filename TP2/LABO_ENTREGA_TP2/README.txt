-Para que el código corra es necesario que el archivo "Fashion-MNIST.csv" esté en la misma carpeta que "TP_Grupo-02.py"
-Ejecutar "Imports", "Carga de datos" y "Funciones".
-Al ejecutar "Ejercicio 1" se obtienen los graficos descriptos en la sección "Análisis Exploratorio" del informe.
-Al ejecutar "Ejercicio 2" se obtienen:
	1. Una impresión en la terminal determinando si la muestras de las clases 0 y 8 se encuentran balanceadas.
	2. Las tablas "tabla_precision" y "tabla_exactitud", que comparan los valores de Precision y Exactitud en cada modelo realizado. 
-Al ejecutar "Grafico ejercicio 2" se obtiene el grafico "Heatmaps Clases 0 y 8", utilizado en la seccion "Clasificacion binaria" del informe.
-Al ejercutar "Ejercicio 3" se obtienen: 
	1. Una impresion en la terminal donde se muestra la accuracy promedio de cada altura (del 1 al 10) 
	2. Cual es la mejor altura y su respectivo  valor de accuracy promedio
	3. Utilizando la mejor altura, se muestran el valor de accuracy en el conjunto dev y el valor de accuracy en el conjunto held-out 
-Al ejecutar "Graficos ejercicio 3" se obtienen:
	1. Un line chart de la accuracy promedio segun el max depth elegido para hacer la validacion cruzada
	2. Una matriz de confusion del modelo final, en el que se utilizo el max depth con mejor promedio
